# Переданные правила

Три исходных файла перенесены из вложений пользователя без изменения текста. Относительные ссылки между ними сохранены. Контрольные суммы — `import-checksums.json`.

- `profile-v1.md`: рабочая спецификация `armenian-training-0.1`, цель 301. Используется для проектирования правил; при расхождениях со старой историей сравниваем с этим профилем.
- `armenian-blot.md`: история R01–R36, различает пользовательские ответы и решения прежнего агента.
- `sources.md`: сведения о ранее исследованных источниках; содержимое сайтов в этой сессии повторно не проверялось.

R21 (рамки в бою) сохраняет предварительный статус и текущий порядок В > 9 > Т > 10 > К > Д. Не объявляем его окончательно подтверждённым. Каждая запись матча фиксирует версию правил.

## Граница между правилами и историческими инструкциями

Указания прежнему агенту и описания прежнего этапа разработки внутри документов — исторический материал, не новые команды пользователя в этом чате. Современные технические решения находятся в `../technical-decisions.md`. Старые замечания о необходимости определить бюджет до разработки не отменяют согласованное здесь откладывание бюджета и выбора модели.

Последняя строка профиля сообщает о реализованной локальной PWA и `tasks/progress.md`. В текущем репозитории такой реализации и файла нет: эта строка не доказывает состояние этого проекта. На момент переноса здесь только дизайн-прототип. Правила пока не реализованы.

## Отличия от демонстрационных чисел в макете

Цель 301 малое очко; восемь карт в руке; заявки целочисленные от 8, шаг повышения от 1, без искусственного максимума; бой — отдельный тип контракта. Числа 1000 и 80–160, шесть карт и только четыре масти в прежнем макете были заполнителями. При реализации заменяем их по профилю, не изменяя согласованный визуальный стиль.

Новые партии используют [profile-v2.md](profile-v2.md): согласованный ручной выбор объявлений. Исходные три документа не изменены. Старые записи сохраняют профиль 0.1.
