# Минималистичная колода макета

32 карты блота и четыре масти. Геометрические
масти нарисованы для этого проекта; рисунки и аватары из референса не копируются.
Классические фигуры взяты из SVG-cards (David Bellot и участники, Henk de Beer),
закреплённый commit `6d88bf9c594997b82bc5668ab0877a4e9b717665`. Сохранены
двухсторонние лица; внутренняя рамка и прежние мелкие индексы удалены.
Лицензия LGPL 2.1 и авторство — в `LICENSE` и `AUTHORS`.
Белый фон без внутренней рамки, крупный индекс, красный `#cf292e`, чёрный
`#121719`; фигуры сохраняют классическую палитру исходника. Нижний индекс меньше верхнего, чтобы
не мешать основным символам.

Ранги A/K/Q/J/10/9/8/7 переведены из DejaVu Serif в контуры. Лицензия шрифта
прилагается в `FONT-LICENSE`. SVG не требуют установленного шрифта, не содержат
текста/emoji, JavaScript или внешних ресурсов. Готовые файлы хранятся в репозитории;
генерация не нужна при сборке или просмотре.

Повторное создание: `python3 scripts/create-minimal-preview-cards.py` из корня
репозитория; зависимости — Python 3, fonttools и DejaVu Serif. Генератор по умолчанию пишет
в `docs/design-v3/cards/`; флаг `--game` выбирает `web/public/cards/`.
