# Проверка публичного Render

14 октября 2026 года. Сервер: https://armenian-blot.onrender.com/ . Клиент GitHub Pages: https://mtigra.github.io/armenian-belote-trainer-app/ .

## Render

- GET `/api/health` по HTTPS: 200, `status=ok`, `protocolVersion=1`. Корневая страница отдаёт игру, manifest и production-ресурсы.
- Настоящий браузерный тест `online.spec.ts` против опубликованного Render прошёл за 24.4 секунды, четыре изолированных контекста Chromium 390×844. Это реальный Ktor и настоящий WSS, без подмены API/состояния игры.
- Проверены четыре разные руки с 32 уникальными картами и отсутствие полного скрытого состояния в текущем snapshot, места и счёт, торговля, все ходы, reload одного гостя, чат другого при продолжающейся партии, ошибки неподключённого тренера, завершение матча и четыре локальных архива. Каждый сохраняет свой чат; существующая офлайн-тренировка не перезаписывается. После завершения серверный запрос записи возвращает 404.
- HTTP-клиент и Chromium проверяют TLS. В среде Codex браузер использует настроенный HTTP-прокси; для доступа Chromium к уже доверенным CA в NSS потребовался запуск с расширенным доступом к файлам за пределами workspace. Проверка сертификатов не отключалась.

## GitHub Pages и локальные проверки

Клиент собран командой `pnpm build:pages` с default API Render. Добавлена миграция прежнего сохранённого origin GitHub Pages; явно выбранный другой API и привязка токена к origin сохраняются. 26 Vitest-тестов, TypeScript и production-сборка прошли. GitHub Pages опубликован коммитом `696180c`; Pages build завершился успешно. Все десять публичных файлов HTTPS-сборки совпадают с локальными байт в байт, JS содержит default API Render.

Публичный `online.spec.ts` против GitHub Pages и Render прошёл за 22.2 секунды: четыре настоящих браузерных клиента, default API не переопределялся. Первый клиент начинал с прежним сохранённым origin GitHub Pages, остальные — с чистыми настройками. Проверен тот же полный матч с реальными HTTP/WSS, восстановлением гостевого места, чатом, локальной историей и серверным удалением завершённого стола. Это также подтверждает CORS и разрешённый Origin WSS для GitHub Pages.

[GitHub Actions](https://github.com/MTigra/armenian-belote-trainer-app/actions/runs/38597783545) для коммита `252ef3a` прошёл: общие критерии JVM/JS, серверные тесты, типы, 26 Vitest-тестов, production-сборка и 7 локальных Playwright-сценариев, сборка Docker и его запуск с лимитом 512 МБ. Два публичных браузерных прогона выполнены отдельно в Codex; CI использует локальный Ktor и не создаёт нагрузку на публичный сервер.

## Ограничения

Тренер пока возвращает `TRAINER_UNAVAILABLE`; внешний AI не подключён. Проверка в Chromium с мобильным viewport не заменяет физические Android/iOS. Длительный сон, принудительные перезапуски Render и большая нагрузка не тестировались. Активные столы всё ещё находятся в памяти и теряются при остановке сервера.
