# Проверка исправлений P14–P20

14 октября 2026. Проверена production-сборка React с настоящим Kotlin/JS
движком и локальный Ktor-сервер протокола 2. Обновлённые Render и GitHub Pages также проверены публично через HTTPS/WSS;
автоматическое развёртывание Render остаётся отключённым.

- **P14:** авторитетные карточные очки взятых взяток, последняя десятка,
  раскрытые бонусы и реблот показаны отдельно от малого счёта партии. Проекция
  EAST/WEST поворачивает обе пары значений. Тесты ядра и клиента проверяют счёт.
- **P15:** выбор до первой карты, раскрытие перед второй взяткой, отсутствие
  бонуса при отказе/таймере, автоматические объявления ботов и блот-реблот.
  Проверены запрет ранней карты, приватность комбинации, отказанные четыре
  восьмёрки, восстановление решения и replay. Профиль 0.1 сохраняется для старых
  записей; экспорт/импорт прежнего полноценного матча проверен клиентским тестом.
- **P16/P19:** одна непрозрачная серая рука; касание играет сразу. Все лица
  используют локальные SVG-картинки с номиналами в контурах. Козырь и торговля
  используют изображения мастей. Источник и лицензии: `assets/card-source`.
  SVG-пути и читаемость проверены визуально; production PWA кеширует 32 лица и
  четыре масти. Браузерный сценарий загружает их после запуска без сети.
- **P17/P18:** новые карты прилетают со своих сторон, четыре карты уходят к
  победителю; центр содержит только текущую взятку. В углу есть миниатюра и
  открываемая полная взятка. Финальный результат ждёт завершения анимации.
  Проверены ровно один сбор взятки, отсутствие старой анимации после reload
  и после обрыва WebSocket во время хода другого игрока. Повторные снимки и
  смена имени не меняют игровой ключ анимации; reduced-motion отключает движение.
- **P20:** четверо гостей задают имена; один меняет имя в лобби. Другие видят
  изменение, ID/токен/место сохраняются. Серверные проверки защищают длину,
  управляющие знаки и авторизацию; смена имени не меняет revision/deadline.
  Завершённые записи содержат имена участников.

Проверки: **80 тестов ядра на JVM + 80 на JavaScript, 17 серверных,
27 Vitest и 8 Playwright-сценариев**. Ядро разыгрывает и повторяет 150 новых
раздач с обоими вариантами выбора объявления, дополнительно сохранены прежние
180 раздач профиля 0.1. Четыре независимых браузерных контекста завершили
онлайн-матч, восстановили место после reload/обрыва связи и сохранили четыре
локальные записи без потери офлайн-тренировки.

Мобильная проверка: 320/390/430 px в портрете, 844×390 и 568×320 в альбомной
ориентации, touch-клик, отсутствие скролла руки; проверены повороты взятки в
просмотре при изменении размеров. Снимки: `previews/friends-fixes/table-*.png`,
`guest-name.png`, `card-art.png`. Настоящие Android/iOS остаются частью P02.

Команды:

```sh
./gradlew :game-core:jvmTest :game-core:jsNodeTest :server:test -PuseSystemNode=true
./gradlew :game-core:jsNodeProductionLibraryDistribution :server:installDist -PuseSystemNode=true
pnpm test
pnpm --filter @blot/web build
pnpm test:e2e
```

Для локального прогона здесь использованы отдельные порты UI 4175 / API 8082,
`E2E_BASE_URL`/`E2E_API_URL` и установленный Chromium; в CI используются
стандартные 4173/8080 и браузер Playwright. TLS-проверка не отключалась.

Первый удалённый прогон `38616908396` собрал и запустил Docker с лимитом
512 МБ, но длинный прежний тест 180 раздач Kotlin/JS превысил стандартные
2 секунды Mocha при параллельной компиляции на runner. Лимит сценария
увеличен до 10 секунд без изменения проверок/выборки. Повторный
[CI 38617620519](https://github.com/MTigra/armenian-belote-trainer-app/actions/runs/38617620519)
для `20a1889` полностью зелёный: JVM/JS, сервер, 27 Vitest, восемь
Playwright-сценариев и Docker с лимитом 512 МБ.
Тренер доступен и из диалога выбора объявления; офлайн-пауза и возврат
к решению проверены отдельным браузерным сценарием.

После CI действующий Render переключился на протокол 2. Прямого доступа
к управлению аккаунтом/deploy-hook у Codex нет; факт успешного обновления
подтверждён публичным `/api/health`, клиентом и реальными проверками.

## Опубликованная версия

- [Render](https://armenian-blot.onrender.com/): протокол 2; полный HTTPS/WSS-матч
  четырёх мобильных Chromium-контекстов прошёл за 33.3 секунды. Проверены имена,
  переименование без потери токена/места, торговля, ручные объявления, reload,
  обрыв WebSocket во время чужого хода, отсутствие старой анимации, независимый
  тренер и четыре локальных архива. Сохранение офлайн-тренировки не потеряно.
- Отдельный публичный офлайн-сценарий Render прошёл за 13.7 секунды: кешированные
  изображения, отказ от объявления, тренер во время выбора, очистка взятки,
  счёт, миниатюра и reload без старой анимации. Все 36 публичных SVG совпадают
  байт в байт с исходниками. HTML ссылается на клиент `index-DMm6y3lW.js`, как
  Docker в успешном CI. Kotlin/JS-файл чистой Docker-сборки отличается хешем
  от локальной инкрементальной сборки; побайтовое совпадение JS не заявляется.
- [GitHub Pages](https://mtigra.github.io/armenian-belote-trainer-app/): `gh-pages`
  коммит `3752657`, [публикация](https://github.com/MTigra/armenian-belote-trainer-app/actions/runs/38618681039)
  успешна. Все 50 файлов проверенной сборки совпали байт в байт по HTTPS.
  Публичный матч с Render API прошёл за 31.6 секунды, офлайн-сценарий — за
  8.1 секунды. Проверен default API, включая прежний сохранённый origin Pages.

Во всех публичных браузерных проверках TLS-валидация включена. Chromium
получил доступ к уже настроенному хранилищу сертификатов среды вне workspace;
это не замена проверке физических Android/iOS по P02.
