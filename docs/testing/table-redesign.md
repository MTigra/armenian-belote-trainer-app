# Перенос согласованного дизайна в игру — P22

Обновление игрового React-клиента по замечаниям и макету P21. Приоритет имеют
последние уточнения пользователя: один тап, затемнение на 20%, объявления
возле игроков, анимация взятки без сообщения о победителе, без результатов
прошлых раздач на столе.

## Что реализовано

- Общий `GameTableShell` для торговли и розыгрыша: симметричное табло
  «Мы — козырь — Они», постоянный общий счёт и текущие карточные очки,
  четыре игрока, собственный аватар, первый выход и текущая очередь.
- `useOrientation` переключает композицию без пересоздания партии.
  Общие стили в `game-table.css`, горизонтальные — в `game-table-landscape.css`.
  CSS Grid, динамическая высота окна, clamp/vmin, сохранение пропорций карт,
  safe-area по четырём сторонам. Масштабирование всего экрана не используется.
- Сортировка мастей ♣/♦/♥/♠, затем сила внутри масти: козырь В/9/Т/10/К/Д/8/7,
  остальные Т/10/К/Д/В/9/8/7. Во время торговли используется текущий контракт,
  а не черновой выбор масти. До первой заявки и в «Бое» все масти некозырные.
- Недоступность определяет `options.cards` движка. Только `brightness(.8)`,
  без grayscale и прозрачности. Козырные карты выделяются тонким тёплым контуром.
- Одна перекрывающаяся рука для 1–8 карт, ход одним тапом. Небольшой подъём
  при касании; hover ограничен устройствами с мышью. Ограничение выделения
  применяется к картам, не мешает работе с полями чата.
- Классические J/Q/K из закреплённого SVG-cards с крупными индексами DejaVu
  в контурах. Чистый белый фон, без внутренней рамки. Те же локальные картинки
  используются на столе, в руке, объявлениях, истории и офлайн.
- Таймер вокруг активного аватара использует `deadlines`, `timerSeconds` и
  поправку серверных часов. Координаты переводятся в перспективу каждого
  гостя. Без таймера остаётся обводка очереди, выдуманного отсчёта нет.
  Реконтра поддерживает два одновременно ожидаемых ответа.
- Терц/50/100/четвёрки/Блот/Реблот появляются возле автора по новым публичным
  событиям. До показа доступны только названия; карты добавляются только из
  `DECLARATION_SHOWN`. После сообщения доступен архив. Старые события не
  повторяются при загрузке или восстановлении соединения.
- Четыре фиксированных места взятки и повороты к игроку сохранены. Существуют
  анимации броска/сбора и миниатюра последней взятки. Сообщения о победителе
  взятки нет. Декоративная надпись в центре и счётчики чужих карт убраны.
- Торговля остаётся в центре в обеих ориентациях. Контра/реконтра, капут,
  пас, выбор масти/боя и запрос показа объявлений используют прежние callbacks.
- Кнопки тренера/объявлений компактны, с доступными названиями. Автоматический
  запрос объявления не открывается поверх чата или меню; после закрытия
  возвращается, если соответствующее действие всё ещё доступно.

## Границы изменений

Правила, допустимость действий, подсчёт очков, сервер, публичная проекция и
сетевой протокол не меняются. Внешний AI и подсветка его рекомендации остаются
отдельной задачей P05. История результатов раздач на столе исключена по
решению пользователя. Архив завершённых матчей сохраняется в прежнем виде.

Портрет и ландшафт используют одинаковые компоненты и данные; отличаются
только композиция и размеры. Никаких новых React-библиотек анимации не добавлено.

## Проверки

Сборка и проверка TypeScript успешны. Prettier проходит. Vitest: **34 теста**;
Playwright: **11 сценариев**, включая полный матч четырёх гостей и отдельную
проверку серверного отсчёта с четырёх относительных мест. Прогон выполнен
на локальном production-клиенте и Ktor, не на подставленных игровых состояниях.
Для воспроизводимых отдельных кадров используются состояния, полученные
действиями настоящего Kotlin-движка.
Набор включает реальную торговлю, допустимые ходы, один тап, сохранение/импорт/
экспорт/replay, офлайн PWA, объявления до/после раскрытия, отсутствие повторов,
чат, восстановление связи и четыре браузерных места.

Типичные размеры: 320×568, 320×640, 390×844, 412×915, 568×320, 844×390,
1280×800. Проверяются центр торговли, одинаковые аватары, границы руки,
отсутствие горизонтального/вертикального скролла и сохранение состояния при
повороте. Это браузерные проверки; прогон на физических Android/iOS остаётся P02.

Скриншоты живого клиента: `previews/table-ui/` — торговля/розыгрыш,
390×844, 320×568, 844×390 и 568×320. Дополнительная проверка подтверждает, что
панель торговли не перекрывает аватары. Публикация GitHub Pages сохраняет
отдельный каталог макета; PWA не подменяет его игровым экраном.

Render использует ручное обновление (`autoDeployTrigger: off`); доступ к его
аккаунту или deploy hook в этой сессии отсутствует. Подготовлен весь клиент
и исходники для `Manual Deploy → Deploy latest commit`.

GitHub Pages: `4277225`, все 51 файлов (с `.nojekyll`) совпадают
с проверенной сборкой по Git blob-хешам. Отдельно прошёл PWA-сценарий
на сборке с префиксом Pages после исключения маршрута макета из fallback.
