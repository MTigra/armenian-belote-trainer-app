# Критерии модуля правил

Источник — `docs/rules/profile-v1.md`, версия `armenian-training-0.1`. Проверяем выбранный профиль, а не произвольный вариант белота. R21 сохранён как временный; отдельный именованный тест защищает его текущее значение.

Все тесты находятся в `game-core/src/commonTest/kotlin/am/blot/core` и выполняются без AI и сети на JVM и JavaScript.

## Границы критериев

Ручные поздние объявления не входят в профиль первой версии: приложение объявляет и показывает автоматически. Вызовы по времени и повторные сетевые сообщения проверяются при реализации Ktor, в ядре нет часов. Скрытые карты остаются внутренними данными; `PlayerView` — предусмотренная граница их выдачи, а `record` разрешён только после матча. Импортированный снимок не должен становиться авторитетным состоянием онлайн-сервера.

## Результат локальной проверки

14 октября 2026 года: 68 тестов на JVM и те же 68 на JavaScript/Node, 0 ошибок и 0 падений. Java 21 (Temurin), Node 24.19.0. Готовый ES-пакет прошёл отдельную проверку через экспортированные функции: партия из 21 сдачи, публичная проекция без скрытых рук, отклонение неверного действия, полный архив и совпадение восстановленного состояния. Проверены сгенерированные TypeScript-описания. Сборка не требует Gradle, установленного в системе: используется Wrapper. Для выполнения в облачном окружении использовались временные кеши и прокси-настройки вне репозитория.
