# Компактный контекст и стратегия — 15 октября 2026

## Что проверяется

Модельный JSON v2 строится из прежнего проверенного PlayerView. Запрос клиента,
сохранение/экспорт, легальность и серверный валидатор действий не меняются.
События текущей раздачи сохраняют торговлю, объявления и их время afterCards;
карты находятся только во взятках. Старые объявления удалены из текущей проекции.
Прошлые раздачи — до 8 итогов, диалог — до 4 целых сообщений / 4000 символов.
Счётчики показывают пропуски. Карты кодируются SJ/S9/S7, кандидаты — строками ID.
Пул outsideHandUnplayed вычисляется без обращения к чужим рукам. Стоимость руки
при каждом козыре вычисляет движок; она не является прогнозом выигранных очков.

Промпт trainer-system-2: конкретные стратегические ориентиры по торговле,
контролю/счёту козырей, старшим картам, поддержке партнёра, выбору дешёвой карты,
информации из торговли и планированию следующего хода. Примеры стратегии не
меняют правил и не заставляют модель выбирать заранее заданную заявку.
Язык инструкции — английский для компактности, ответы — русский.
Groq, openai/gpt-oss-120b, reasoning_effort=medium, max_completion_tokens=2048.

## Реальные вызовы через локальный Ktor

1. Точная рука пользователя на первом ходу: пики В–9–7, бубны 10–Т,
   червы К, трефы В–7. HTTP 200 за 9,48 с: модель предложила 8 пик,
   9 пик дала альтернативой. 4145 input / 1165 output / 5310 total токенов.
   Это улучшение относительно сообщённого пользователем паса, но не доказательство,
   что 8 — оптимальный размер заявки. Прогноз стратегии кодом не проверяется.
2. Вторая раздача перед третьей картой (тот же PlayerView, что в прежнем примере):
   HTTP 200 за 8,01 с, 4023 input / 862 output / 4885 total токенов.
   До сокращения 6200 input: снижение на 35,1% с расширенным стратегическим промптом.
   Модель выбрала объявить имеющийся терц треф 10–В–Д вместо отказа.

При итерациях были замечены ошибочная арифметика, необоснованный отказ от
объявлений, неточные русские названия карт и обещание гарантированного бонуса.
Вынесена арифметика в движок; промпт уточняет отсутствие штрафа за проигрыш
сравнения, отсутствие расхода карты и отсутствие гарантии бонуса до сравнения.
Последние уточнения не превращают модель в доказанный стратегический анализатор.
Последний ответ про терц всё ещё содержал ошибочные пояснения (гарантированный
бонус и «сохранить карты» при отказе); правильное действие не означает правильную
аргументацию. P04 остаётся открытой, нужны разнообразные ситуации и сравнение моделей.

## Автоматические проверки

42 серверных теста: текущая раздача без старых объявлений, время событий,
итоги/пересдачи и счётчики, приватность пула карт, раскрытые руки только all_hands,
полные сообщения с ограничением истории, явный NONE для боя, точная стоимость
карточной руки, наличие исполнимой заявки 9 пик и остальные проверки провайдера.
Воспроизводимые запросы генерируются тестом в server/build/trainer-fixtures.
Образцы опубликованы в docs/examples/trainer/groq-request-*.json без ключей.

## Публикация

Render и CI: выполняется. Авторизованный публичный запрос не выполняется без
кода доступа; реальные вызовы выше локальные, с отдельным тестовым кодом.
