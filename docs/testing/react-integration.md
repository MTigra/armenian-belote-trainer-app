# Проверка подключения движка к React

Проверено 14 октября 2026 года. Общий Kotlin-модуль не изменялся: интерфейс использует его готовый ES-пакет. TypeScript не реализует торговлю, допустимость карт или подсчёт очков самостоятельно.

## Результаты

- TypeScript: проверка типов проходит.
- Vite production: сборка проходит; отдельные кешируемые блоки React, движка и интерфейса, PWA-кеш около 610 КиБ без внешних ресурсов.
- Vitest: 10 тестов, 0 падений. Проверены реальный адаптер движка, приватная проекция, выбор акторов ботов, сохранение, атомарное завершение, импорт/экспорт, отказ AI и отсутствие карт объявлений в UI до их публичного показа.
- Playwright/Chromium: 4 сценария, 0 падений. Реальная торговля, законные карты, пауза ботов в чате, сохранение и точное продолжение после reload, отказ AI без изменения партии; реальный завершённый матч, история, экспорт/импорт и просмотр полной раскладки; production-запуск без сети после первого кеширования; касание карты без подтверждения и размещение взятки по местам игроков при смене ориентации.
- Сборка для GitHub Pages с базовым путём `/armenian-belote-trainer-app/` прошла те же 10 Vitest и 3 Playwright-проверки. Manifest, иконка, service worker и ресурсы используют путь публикации. Готовые файлы загружены в ветку `gh-pages`; API GitHub подтвердил статус `built`, публичный HTTPS-адрес отдаёт production-сборку.
- Публичный адрес дополнительно проверен Chromium на 390×844: открытие меню, настоящая торговля с восемью картами, чат на паузе, активация service worker и перезагрузка без сети с восстановлением партии. Ошибок JavaScript нет. Все 10 опубликованных файлов побайтно совпали с локальной проверенной сборкой. Для браузерной проверки в Codex отключена проверка его прокси-сертификата; HTTPS отдельно проверен системным trust store через curl/urllib. Скриншоты: `previews/published-mobile-menu.png`, `previews/published-mobile-coach.png`.
- Визуально проверены 390×844, 320×740, 844×390, 568×320, 1024×768, 1440×980. Ошибок JavaScript и горизонтального переполнения страницы нет. Рука — один адаптивный ряд без прокрутки; номинал и масть каждой карты видны и не закрыты соседней картой. Дополнительно проверены геометрия карт и отсутствие перекрытия кнопкой тренера.

Для быстрого завершения одного браузерного теста сделана разрешённая высокая заявка 400: по правилам она проваливается и приводит к достижению цели 301. Счёт и состояния не подменяются фикстурами; партия разыгрывается через реальные кнопки и общий движок. Многосдачные матчи уже проверены тестами ядра.

Тестовые исходники: `web/src/lib/*.test.ts`, `web/tests/game.spec.ts`. Команды запуска в `web/README.md`. CI дополнен тестами интерфейса; удалённые запуски пока останавливаются на Kotlin JS lock-файле до выполнения веб-проверок (P01 в [roadmap](../roadmap.md)).

## Исправления по проверке на телефоне (P13)

- Убраны горизонтальный скролл руки и отдельное подтверждение хода. Касание разрешённой карты сразу передаёт действие движку; полный матч разыгран через этот интерфейс.
- Увеличены номиналы и масти: в портретной руке 22/20 px вместо прежних 19/15 px; при торговле вместо 17/13 px. Карты остаются в одном ряду, их шаг зависит от ширины стола и количества карт.
- Взятка привязана к `seat`, а не к порядку появления карт: SOUTH снизу (0°), NORTH сверху (180°), WEST слева (90°), EAST справа (−90°). Та же раскладка применяется в просмотре истории.
- Отдельный touch-сценарий проверяет все восемь карт, один ряд без скролла, уменьшение руки после одного касания, отсутствие кнопки подтверждения, правильную принадлежность карты и геометрию/поворот всей взятки при смене ориентации.
- Снимки исправленного интерфейса: `previews/hand-fix-*-bid.png`, `previews/hand-fix-*-table.png`. Боты остановлены браузерными часами после настоящей завершённой взятки только для стабильного сравнения снимков; игровая логика и записи не подменялись.
- Обновлённая версия опубликована в GitHub Pages (ветка `gh-pages`, коммит `d4208a3`). Все 10 файлов совпали с проверенной сборкой. Публичный сайт дополнительно проверен с touch-событиями на 320×740: один ряд, ход одним касанием, карта SOUTH снизу, отсутствие подтверждения, пауза в чате и восстановление после перезагрузки без сети; ошибок JavaScript нет.

## Ограничения

Автоматические проверки выполнены в Chromium на эмулированных размерах и с touch-событиями. Пользователь сообщил замечания после проверки с телефона; полный прогон на физических Android/iOS остаётся задачей P02. Service worker работает только в production и после первоначального кеширования; Vite dev требует сеть. Ktor, WebSocket-столы и AI-провайдер ещё не реализованы. Чат показывает явную ошибку недоступности, сохраняет вопросы, приостанавливает офлайн-ботов и не отправляет скрытые руки.
