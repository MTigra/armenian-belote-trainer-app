## Настройки Gemini

Пользователь сообщил, что создал и привязал Environment Group `belote`.
Подключённый MCP не предоставляет чтение списка групп и их связей, поэтому
имя/привязку независимо не перечисляли и значения секретов не извлекали.
Группу и переменные не изменяли. Проверено применение конфигурации в процессе:

```text
trainer configuration apiKeyConfigured=true accessCodeConfigured=true model=gemini-3.8-flash
```

Это признаки наличия ключа и корректного четырёхзначного кода, без их значений.
Проверка не доказывает правильность самого API-ключа у Google.
Отдельный отрицательный HTTP-запрос с заведомо неформатным кодом получил
401 TRAINER_ACCESS_DENIED, retryable=false; CORS разрешил https://mtigra.github.io.
Реальный авторизованный запрос к Gemini в публичной версии не выполнялся:
код доступа не передавался Codex. Предыдущий реальный локальный вызов той же
интеграции описан в [trainer-integration.md](trainer-integration.md).

## Публичные проверки

- Render `/api/health`: HTTP 200, protocolVersion=2.
- Render отдаёт новый клиент с source/reference, all_hands и проверкой ответа.
- Все 50 файлов приложения GitHub Pages побайтно совпали с локальной Pages-сборкой.
- `trainer.spec.ts`: два сценария прошли на GitHub Pages и два на Render.
  Проверены структурированный ответ, повтор requestId, reload, обе перспективы
  review, сохранение вопроса и ответа в exportVersion=2. Ответы модели в этих
  сценариях имитируются браузерным перехватом, а не расходуют реальную квоту.
- `online.spec.ts`: полный матч четырёх независимых гостей через настоящий
  HTTPS/WSS GitHub Pages → Render прошёл за 29,8 секунды. Проверены приватные
  проекции, возврат места, задержанный mock-ответ о прошлом моменте, продолжающаяся
  игра и четыре локальных архива с раздельным чатом.
- Ошибок уровня error в Render после старта новой версии при этой проверке нет.

Первую проверку Pages запустили до окончания распространения новой версии;
она получила старый контракт. После завершения Pages deploy проверили совпадение
50/50 файлов и повторили сценарии успешно. Изменений кода для этого не понадобилось.
