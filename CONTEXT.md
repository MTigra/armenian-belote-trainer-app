# Термины проекта

| Термин | Значение |
| --- | --- |
| Матч | Игра двух команд по два участника, доступная для последующего просмотра и обсуждения. |
| Учебная игра с ботами | Игра пользователя с программными участниками, доступная без интернета. |
| Приватный стол | Онлайн-игра с друзьями, в которую участники входят по коду. |
| Тренер | Помощник, отвечающий на вопросы об игре и её прошлых моментах. Доступен во всех игровых режимах. |
| Информация игрока | Собственная рука, публичные заявки, совершённые ходы и другие доступные этому игроку сведения. Не включает скрытые карты других участников. |
| Разбор с позиции игрока | Обсуждение решения на основании информации, которую игрок имел именно в рассматриваемый момент. |
| Разбор с раскрытыми картами | Анализ завершённого матча с доступом к рукам всех участников. |
| Скачанный матч | Сохранённый для просмотра без интернета завершённый матч. |
| Гость | Участник без зарегистрированного аккаунта. |
| Бот первой версии | Программный участник, совершающий разрешённые действия без оценки их стратегической силы. |
| Локальная история | Матчи, сохранённые на конкретном устройстве и доступные без интернета. |
| Момент вопроса тренеру | Зафиксированный момент матча, к которому относится вопрос и ответ тренера, независимо от дальнейших ходов. |
| Таймер стола | Выбранное для конкретного стола ограничение времени на действие игрока. Значения и последствия истечения уточняются. |
